# PixelNotes

A pixel-art retro office sidebar for VS Code — take notes, attach code references, and send context to AI, all without leaving your editor.

## Features

- 🏠 **Pixel-art office** — an animated retro room with a scribe, roaming NPCs, and a cat that lives in your sidebar
- 📝 **Note editor** — create, edit, search, and tag notes scoped to your workspace
- 📌 **Pinned notes** — pin important notes so they always appear at the top of the list
- ☑️ **Interactive checkboxes** — write `- [ ] task` in any note and check items off right in the UI
- 🔗 **Code references** — attach file links, single lines, or block ranges to any note; click to jump back instantly
- 🤖 **Send to AI** — push a formatted note directly into GitHub Copilot Chat
- 🧠 **AI summarize** — one-click summary of any note sent straight to Copilot
- ✨ **Generate from selection** — right-click highlighted code → create a note and ask AI to explain it
- 💾 **Export note** — save any note as a `.md` file with all references and tags included
- ✅ **Auto-save** — notes save automatically as you type
- 🔗 **Note linking** — type `[[Note Title]]` to link between notes
- 🔥 **Daily streaks** — keep a writing streak going; your flame badge grows with consecutive days
- ⌨️ **Typing speed tracker** — live WPM displayed while you write
- 🎨 **Seasonal decorations** — Christmas lights, Halloween pumpkin, cherry blossoms depending on the month
- ☕ **Break room** — switch to the break room for a chill pixel vibe (and a few games)
- 🎮 **Arcade games** — click the Pong or Breakout cabinet in the break room to play
- 🐱 **Easter eggs** — click the coffee mug, the cat, the monitor, the plant, or the bookshelf; try the Konami code

## Usage

1. Click the **PixelNotes** icon in the Activity Bar
2. Hit **+ New Note** or use a template (Bug Report, Task List, Meeting Notes, Research)
3. Right-click any line in the editor → **Add Code Reference to Note**
4. Click a file, highlight multiple lines, or select an entire file — all supported as references
5. Right-click selected code → **Explain Selection with AI & Create Note** to auto-generate a note
6. Click **Summarize ✦** to get an AI summary of the current note
7. Click **↓ Export** to save the note as a markdown file
8. Switch to the **☕ Break** room tab and click an arcade cabinet for Pong or Breakout
