# PixelNotes

A pixel-art retro office sidebar for VS Code — take notes, attach code references, and send context to AI, all without leaving your editor.

## Features

- 🏠 **Pixel-art office** — an animated retro room with a scribe, roaming NPCs, and a cat that lives in your sidebar
- 📝 **Note editor** — create, edit, search, and tag notes scoped to your workspace
- 🔗 **Code references** — attach file:line links to any note; click to jump back to that exact spot
- 🤖 **Send to AI** — push a formatted note directly into GitHub Copilot Chat
- ✨ **Auto-save** — notes save automatically as you type
- 🔗 **Note linking** — type `[[Note Title]]` to link between notes
- 🎨 **Seasonal decorations** — Christmas lights, Halloween pumpkin, cherry blossoms depending on the month
- 🐱 **Easter eggs** — click the coffee mug, the cat, the monitor, the plant, or the bookshelf; try the Konami code

## Usage

1. Click the **PixelNotes** icon in the Activity Bar
2. Hit **+ New Note** or use a template (Bug Report, Task List, Meeting Notes, Research)
3. Right-click any line in the editor → **Add Code Reference to Note**
4. Click **Send to AI ✦** to open Copilot Chat with your note pre-filled
