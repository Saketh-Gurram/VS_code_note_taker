## Hidden interactions

| Trigger | Effect |
|---|---|
| Click the **coffee mug** on the desk | ⚡ Speed boost — the scribe types like crazy for a few seconds |
| Click the **cat** | 💬 Meow bubble appears above its head |
| Click the **monitor** | 🟩 Matrix mode — green katakana rains down the screen |
| Click the **plant** | 🌿 It wiggles |
| Click the **bookshelf** | 📖 The roaming NPC grabs a book and reads |
| Click any **roaming NPC** | 💬 A speech bubble pops up with a random programmer quote |
| Click the **TV** in the break room | 📺 Toggles the TV between static and a pixel show |
| Click the **Pong cabinet** in the break room | 🏓 Launches a Pong minigame (move your mouse to control the paddle) |
| Click the **Breakout cabinet** in the break room | 🧱 Launches a Breakout minigame (mouse = paddle, Space = launch) |
| Click the **foosball table** | ⚡ TURBO mode — the table animation goes 6× speed for 5 seconds |
| Click the **coffee machine** | ☕ COFFEE BREAK — both NPCs sprint to the machine; steam billows |
| Click the **couch** | 💤 Nap time — NPCs shuffle over and doze off; Zzz bubbles float up |

## Keyboard secrets

| Trigger | Effect |
|---|---|
| **↑ ↑ ↓ ↓ ← → ← → B A** (Konami code) in the **Note Room** | 🕺 Disco floor — the whole room pulses with rainbow tiles |
| **↑ ↑ ↓ ↓ ← → ← → B A** (Konami code) in the **Break Room** | 🎉 Party mode — rainbow floor + the TV goes full rave screen (toggle) |
| **[Esc]** while playing Pong or Breakout | Exit the arcade game back to the office |
| **[R]** while playing Pong or Breakout | Restart the current game |

## Note title triggers

| Note title (exact, case-insensitive) | Effect |
|---|---|
| `sudo` | 🔐 "Root access granted" banner flashes |
| `hello` | 👋 All NPCs stop and wave |
| `snake` | 🐍 The canvas becomes a playable Snake game — Arrow keys or WASD to steer, R to restart, Esc to exit |
